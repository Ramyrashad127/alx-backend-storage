This repository provides comprehensive coverage of database management and persistence mechanisms in modern software engineering, spanning **Advanced Relational Databases (MySQL)**, **Document Stores (MongoDB / NoSQL)**, and **In-Memory Caches & Key-Value Stores (Redis)**.

---

## Curriculum & Directory Structure

| Module Directory | Storage Engine | Key Concepts & Implementations |
| :--- | :--- | :--- |
| [0x00-MySQL_Advanced](./0x00-MySQL_Advanced) | MySQL (Relational) | Constraints, Table Optimization, Indexing, Triggers, Stored Procedures, Functions, Views |
| [0x01-NoSQL](./0x01-NoSQL) | MongoDB (Document) | BSON Documents, PyMongo, Querying, Updating, Aggregation Pipelines, Nginx Log Analysis |
| [0x02-redis_basic](./0x02-redis_basic) | Redis (Key-Value) | `redis-py`, Expiring Keys, Function Call Trackers, Decorator Design Pattern, Web Cache |

---

## Environment & Requirements

- **OS**: Ubuntu 20.04 LTS
- **MySQL**: Version `8.0`
- **MongoDB**: Version `4.4`+ with `pymongo`
- **Redis**: Version `5.x`/`6.x` with `redis-py`
- **Python**: Version `3.8.5` adhering to PEP 8 / `pycodestyle`
